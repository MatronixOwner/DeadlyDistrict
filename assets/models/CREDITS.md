# Модели

Все модели в этой папке сделаны **Quaternius** (https://quaternius.com) и распространяются по лицензии
**CC0 1.0** — общественное достояние: их можно свободно использовать, изменять и распространять,
в том числе в коммерческих проектах, без указания автора. Автора мы всё равно называем — спасибо ему.

Текст лицензии: https://creativecommons.org/publicdomain/zero/1.0/

| Что | Набор Quaternius | Откуда взят файл |
|---|---|---|
| Персонажи и клипы анимации (`chars/`, `anims/`) | Ultimate Modular Men, Ultimate Modular Women | glTF из репозитория `HamaDler/sami-park-mayhem` |
| Легковые машины, такси, полиция (`veh/`) | Cars | OpenUSD из репозитория `chibifire-stages/quaternius-stage` |
| Фургон, скорая, автобус | Public Transport | там же |
| Пикап, «Бизон», грузовики | Zombie Apocalypse Kit | там же |
| Пистолет, «Узи», дробовик | Ultimate Gun Pack | там же |
| Автомат, гранатомёт, гранаты | Toon Shooter Game Kit | там же |
| Бита | Zombie Apocalypse Kit | там же |

Файлы `.bam` получены из исходников скриптом `tools/import_models.py`: он сваривает вершины,
упрощает привязку к скелету (чтобы анимация считалась быстрее), заменяет материалы простыми цветами
и раскладывает детали по именованным узлам, чтобы игра могла перекрашивать одежду и кузова.

Остальная графика игры (город, текстуры, значки), звуки и музыка созданы программным кодом проекта.
